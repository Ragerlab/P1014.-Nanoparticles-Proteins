# An In Vitro Model for Human Airway Epithelial Cells Preloading with Polyethylene Terephthalate Micronanoplastic Particles

This code was generated to support the manuscript titled 'An In Vitro Model for Human Airway Epithelial Cells Preloading with Polyethylene Terephthalate Micronanoplastic Particles', soon to be published.

# 1. Group Distribution Analyses
- Determining if there are statistically significant differences in protein expression after exposure to nanoplastics (NP1 and NP2) at differet does (0.05 mg/L and 0.1 mg/mL)

# 2. Volcano Plots
- Visualizing the aforementioned differences in protein expression after treatment exposure at various doses
